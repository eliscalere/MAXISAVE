Report an issue

The fastest way to get help is to open an issue on GitHub. Include what you were doing, what you expected, and what happened instead — a screenshot of the status pill helps a lot.

Common questions

My draft didn't come back after a refresh

Check the corner of the page for the status pill first — it should read "Draft restored from …" a moment after the page loads. If it says "Autosave on" instead, no draft was found for that browser profile; drafts are per-profile and per-computer, so they won't appear if you're signed into a different Chrome profile or a different machine.

Some Involved Parties rows are missing or blank

This should be fixed as of the current version — restoring now retries until every row is back, and a page bug in the Maxient form that could leave a newly added row invisible (stuck at zero opacity) is worked around automatically. If you still see this, please open an issue with the version number from chrome://extensions.

A required field stayed red after I answered it

This was a bug in an earlier version, caused by the Clear button calling the browser's native form reset, which silently wiped the underlying value of radio and checkbox answers. It's fixed — Clear no longer resets the form that way. Update to the latest version if you still see it.

Do attachments get saved?

Automatically, same as every other field — no separate step. They save locally and, once you're signed in, sync to your own Google Drive with the rest of the draft.

How long is a draft kept?

Indefinitely, with one exception: drafts older than 14 days are discarded automatically. A draft is also deleted the moment you press Submit or Clear.

Is my data sent anywhere?

Signing in with Google is required to use Maxisave's saving features — once signed in, drafts, attachments, and history live in a hidden folder in your own Google Drive, not on any server Maxisave operates. "Format with AI" is a separate, genuinely opt-in feature that sends the description and involved parties' names/IDs to an AI you choose, only when you click its button. See the privacy policy for the full picture.
